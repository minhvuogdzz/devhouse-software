# Architecture and Implementation Decisions

This log records simple, consistent decisions made where documents were unspecified or environment-specific choices were needed.

- 2026-10-02: Local MongoDB community service on port 27017 used for local dev while root compose.yml provides the containerized definition for container environments.
- 2026-10-02: Yarn 4 with nodeLinker: node-modules configured for root workspace and subprojects.
- 2026-10-02: Brand blue provisional OKLCH selected as `oklch(52% 0.22 258)` for light theme and `oklch(68% 0.20 255)` for dark theme meeting WCAG AA contrast standards.
- 2026-10-02: React Router v7 used in framework mode (SSR) for `apps/web` and Vite SPA data router mode for `apps/admin`.
- 2026-10-02: Semantic alpha overlays (`bg-fg/50 backdrop-blur-xs`) used for modals and drawers to ensure strict compliance with `theme/no-raw-palette`.
- 2026-10-05: The public site follows the company direction document (website, hosting, domain and security as packages). Header menu: Dịch vụ, Gói dịch vụ, Mẫu website, Quy trình, Về chúng tôi, Liên hệ. The Solutions, Projects, Technologies, Blog and Careers pages still exist but are left out of the default menu and footer until they have real content; an admin can add them back in Admin → Navigation.
- 2026-10-05: "Mẫu website" (products) are cards with a 4:6 ratio. Up to three pictures rotate every 3 seconds (paused for visitors who prefer reduced motion). Hovering, focusing or tapping shows the category, rating, views and the demo button. Rating and views are typed by an admin; nothing is counted automatically. Area ("mảng") and type ("thể loại") are both managed in Admin → Categories.
- 2026-10-05: A demo opens inside the site, in a dialog with an iframe, and never in another tab. The frame is sandboxed (scripts, forms and modals allowed; popups and navigating the host page not allowed). A demo link must start with https:// (http only for localhost). A site that forbids being framed shows an empty frame plus a hint to contact us; there is deliberately no "open in new tab" fallback. If a Content-Security-Policy is added at the edge, `frame-src https:` must be allowed.
- 2026-10-05: Prices and support levels are not decided by the company yet. Package prices are optional, the site shows "Liên hệ báo giá" until an admin fills them in, and no number is invented. The recurring fee is per quarter or per year, never monthly. Internal parts of the direction document (margins, targets, risks, roadmap) are not published.
- 2026-10-05: Pictures uploaded from a computer are converted to WebP in the browser (at most 2000 px on the long side, under 1 MB), uploaded to Cloudinary with a signed request, and then checked again by the API through Cloudinary's Admin API. Pictures are shown resized (`f_auto,q_auto,c_limit`).
- 2026-10-05: Page text, menus and company details have code defaults. The database stores only what an admin changed, so the seed no longer copies navigation or page text and improved defaults reach every site that has not customised them.
- 2026-10-05: The Terms of service page (`/terms`) is DRAFT wording written from the company direction document. The company must review it before it is treated as final. It is edited in Admin → Pages → Terms of service.
- 2026-10-05: The contact form no longer asks for a budget range (prices are undecided and the old ranges were for large projects). A free-text "interested in" field is prefilled from `?interest=` on links such as "Tư vấn gói này" and is stored as the request's `subject`.
- 2026-10-05: Colour tokens `scrim` and `on-scrim` (the same dark film and light text in both themes) are used for text over photographs. The tokens `surface-raised`, `surface-sunken`, `*-subtle`, `*-surface` and `border-focus` that screens already used are now defined in both themes.
- 2026-10-05: Projects ("Dự án") are set up like website templates: up to three card pictures, an area ("mảng", Categories type `project-segment`) and a type ("thể loại", type `project`), rating, views and a demo link that opens inside the site, plus an optional case study (client, challenge, solution, results). The stored name stays `title`. Older projects keep working: a cover image is shown as the card picture and, when an admin opens and saves the project, moved into the card pictures; the old project link becomes the demo link if it can be shown in a frame. The public project page no longer shows a made-up stand-in project and returns 404 for an unknown project.
- 2026-10-05: Admin list pages read the paging details from `response.pagination`, which the API sends as `meta.pagination`; the admin client now copies it over, so page 2 and beyond work. The contact request list returns the list itself as `data` (it used to be wrapped one level deeper, which crashed the inbox).
- 2026-10-05: `PATCH /reorder` is registered before `PATCH /:id` for services, solutions, technologies and projects; before, "reorder" was taken as an id. ESLint now fails on a component that is used but not imported (`react/jsx-no-undef`).
- 2026-10-05: Every list on the website (services, packages, templates, projects, steps, values, pictures, blog posts, technologies...) is drawn by one `Collection` component, and an admin chooses how for each list under Admin → Pages: grid, list (one item per row) or slide. Grid and slide take the number of items visible at once for phones, tablets and computers. A slide either moves one page at a time (arrows, and dots in one of three looks: plain dots, a progress bar that fills while it waits, or a pill that glides) or runs without stopping like a ticker. A slide pauses while the pointer, the keyboard or a finger is on it, when it is off screen or the tab is hidden, and it does not move for visitors who prefer reduced motion. The setting lives with the page content (`display`), so it follows the same "defaults in code, only changes in the database" rule. By default the services and templates on the home page run as non-stop slides.
- 2026-10-05: The About page is about the company (story, vision and mission, what we do, four values, service terms) and no longer introduces the leadership; the org chart and the founders' names were removed. It has a picture slide with any number of pictures, uploaded from the computer like every other image (WebP, under 1 MB), and the section stays hidden until pictures exist.
- 2026-10-05: Services have two levels. The four groups from the company direction document each hold the kinds of service named there (19 in all, such as Landing page, Cloud server, Domain renewal, Website firewall). Each has its own page that explains how it is set up, step by step (`process`), what is included and common questions, and any part left empty is simply not shown. An admin can edit, hide or add kinds; a group that still has kinds inside cannot be deleted and a kind cannot hold others. Response times, hours and prices are not written anywhere because they are not decided.
- 2026-10-05: The blog list no longer invents a post when the API cannot be reached (no made-up data), and its heading, search text and list layout now come from the page content.
